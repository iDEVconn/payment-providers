## Rulings
- Ruling: ProductType is not known at subscription creation, so `shippingPreference` defaults to `NO_SHIPPING` unless `productType === 'PHYSICAL'` (then PayPal's default applies); an explicit `shippingPreference` always wins.
- Ruling: debug id has no column on the operation row, so it is appended to `failureMessage` (only if it matches `[\w.-]{1,128}`) and carried on the thrown error.
- Ruling: tests that encoded defects were changed: `subscription-lifecycle-provider-plan` "legacy planOperationId" no longer asserts `getPlan` is not called (now asserts it is); `subscription-lifecycle-service` "copies billing-plan offeringRef" uses a `getPlan` that echoes the plan id.
